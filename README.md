# Tip Calculator (Calculateur de pourboire)

Une application Android développée avec **Jetpack Compose** permettant de calculer rapidement le montant d'un pourboire en fonction du montant de l'addition et du pourcentage souhaité, avec la possibilité d'arrondir le résultat au supérieur.

## 📱 Fonctionnalités

* **Calcul dynamique** : Mise à jour en temps réel du pourboire dès la saisie des montants.
* **Personnalisation** : Champ pour spécifier un pourcentage de pourboire personnalisé.
* **Option d'arrondi** : Un interrupteur (`Switch`) permet d'arrondir le montant du pourboire à l'entier supérieur.
* **Interface Material 3** : Design moderne intégrant des champs de texte stylisés avec icônes indicatives (`leadingIcon`).

## 🛠️ Technologies & Outils

* **Langage** : Kotlin
* **UI Framework** : Jetpack Compose (Material 3)
* **Architecture** : Single-Activity avec état composable (`remember`, `mutableStateOf`)
* **Minimum SDK** : API 21+
